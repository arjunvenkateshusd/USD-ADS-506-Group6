# USD-ADS-506-Group6
### Group 6: CAISO Hourly Load Forecasting  

## Overview  
This repository contains the collaborative work for our ADS 506 Final Team Project.  
Goal is to analyze and forecast hourly CAISO electrical load using classical time series methods, and to communicate insights to both technical and non-technical audiences.

The project includes:
- Exploratory Data Analysis (EDA)
- Data cleaning and feature preparation
- Time series decomposition
- ARIMA and ETS model training/evaluation
- Train/test validation
- Executive-level Data Story Presentation (Module 6)
- Technical Written Report (Module 7)

---

## Dataset  
We used the CAISO Historical EMS Hourly Load dataset, which captures electricity demand across California balancing authorities.  
Data spans 8,760 hourly observations and includes timestamp, utility regions, weekday/weekend indicators, and derived date-time features.

The dataset is pre-processed and stored in this repository as:
- `processed_ems_load_data.csv`
